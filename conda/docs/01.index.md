## Conda — Environment Manager

```bash
conda env list
conda info --envs

conda create --name env-name
conda remove --name env-name --all
conda activate env-name

conda create --prefix env-path python=3.11
conda remove --prefix env-path --all
conda activate env-path
conda deactivate

conda install -n env-name pkg-name

conda list
conda list -n env-name
conda list -p env-path
```
